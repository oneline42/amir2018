# آمنة للدعاية والإعلان — فيديو إعلاني

فيديو عمودي (1080×1920، 30 إطار/ثانية، 37 ثانية) بنفس أسلوب فيديو المرجع: خلفية داكنة ولمسات حمراء وحركة نصوص عربية وواجهات متحركة.

- `amna.mp4`: الفيديو النهائي مع الموسيقى.
- `scene.html`: المشهد. افتحه في المتصفح لمعاينة حيّة.
- `render.js`: يحوّل المشهد إلى فيديو: `node render.js` (يحتاج Playwright و ffmpeg).
- `img/`: صور مجانية من Unsplash (رخصة Unsplash).
- `fonts/`: خط Alexandria (رخصة SIL OFL).

رقم التواصل في الفيديو: 0592077770
