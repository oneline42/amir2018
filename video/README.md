# فيديو أنيق

فيديو مدته 15 ثانية بدقة 1920×1080 و30 إطاراً في الثانية، بخلفية داكنة ولمسات ذهبية.

- `scene.html`: مشهد الحركة. افتحه في المتصفح لتشاهد معاينة حيّة.
- `render.js`: يحوّل المشهد إلى فيديو `elegant.mp4` مع موسيقى هادئة. شغّله بالأمر `node render.js`، ويحتاج إلى Playwright و ffmpeg.
- `fonts/`: الخطوط المستخدمة (Amiri و Reem Kufi و Cormorant Garamond)، وكلها برخصة SIL OFL.
